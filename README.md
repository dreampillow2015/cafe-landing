# cafe-landing

간단한 카페 랜딩 페이지 예제 프로젝트예요. 순수 HTML과 CSS만으로 만들어서 별도 설치나 빌드 없이 바로 열어볼 수 있어요.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 랜딩 페이지 본문 (히어로, 대표 메뉴, 카페 소개, 오시는 길, 푸터) |
| `style.css` | 페이지 스타일 (카페 느낌의 브라운/크림 색상, 모바일 대응) |

## 사용 방법

1. 이 레포를 클론하거나 파일을 내려받아요.
2. `index.html`을 브라우저(크롬 등)로 열어요.

```bash
git clone https://github.com/dreampillow2015/cafe-landing.git
```

## 수정 포인트

- 카페 이름, 메뉴, 가격은 `index.html`에서 바꿀 수 있어요.
- 주소, 영업시간, 전화번호는 임시 문구라 실제 정보로 바꿔야 해요.
- 색상은 `style.css` 맨 위의 `:root` 변수에서 조정할 수 있어요.
